# VASP Community Mods — experimental preview

Независимые кодовые модули для Victory At Sea Pacific **1.14.2**, Unity 5.6.7f1 / Mono x64 / .NET 3.5. `releaseReady: false`. Неофициальный проект; не связан с Evil Twin Artworks.

## Модули
- **H1**: жизненный цикл авиации и ведущего; **H2**: топливо/восстановление авиационного ИИ; **H3**: проверки ссылок интерфейса; **H4**: навигационные порталы; **H5**: адресация выбранного корабля в приказах. Сохранены адресные IL-гварды и общая транзакция R1–R5. Публичные начальные настройки: только H1; существующие настройки сохраняются. Изменение H1–H5 требует полного перезапуска игры: снятие патчей не отменяет уже восстановленные объекты.
- **Автопатруль**: средний/MAX безопасный радиус, резерв топлива, возврат, повторный штатный вылет после заправки и отмена ручным приказом. Задания хранятся в памяти: после загрузки назначаются заново. Отключение прекращает автоматизацию и передает звенья штатной логике возврата.
- **Конвои**: редактор связей путевых точек, стабильный слот PointGraph, отдельные запросы морского/конвойного пути, конечный порт, защита устаревших ответов и учет положения флагмана в строю (база Interface Tools 0.1.2). Пунктир обозначает сеть собственных конвоев снабжения, не запретную область. «Готово», Esc и ПКМ завершают редактирование.
- **RU**: 117 дополнений, включая «Прибытие» вместо ETA; не полный перевод. Имена и позывные автоматически не переводятся. Остаточные английские ключи записываются локально в `BepInEx/config/VaspUntranslated.csv`.

## Почему BepInEx
Проверенный `ModManager` имеет одну `activeModName`; штатный формат загружает данные CSV/XML и AssetBundle, а не эти C# плагины. Небольшой мост добавляет дочернюю секцию непосредственно к `UIModOptions` — существующему экрану «Модификации». Он не создает фиктивные записи, не заменяет активный сторонний мод и не вызывает `LoadMod`/`DisableMods`. Нет отдельного окна или постоянной панели.

## Установка и использование
Требуются Windows x64, указанная версия игры и отдельно установленный **BepInEx 5.4.23.5 x64**. Скачивайте зависимость только из [официального релиза](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5), архив `BepInEx_win_x64_5.4.23.5.zip`. Существующий загрузчик или `winhttp.dll` нельзя перезаписывать вслепую.

Закройте игру и следуйте [INSTALL.md](INSTALL.md). Сначала сохраните резервную копию кампании. Установщик проверяет сборку игры и владение файлами; неизвестные DLL не перезаписывает. Не копируйте новые DLL рядом со старыми экземплярами тех же плагинов.

Откройте штатный раздел **«Модификации»**. Секция Community Mods содержит независимые действия и показывает фактическое состояние. Для H1–H5 отдельно показан отложенный выбор после перезапуска. Конвои, патруль и RU имеют live API; до завершения Unity-проверок не считать их безопасность подтвержденной. Настройки остаются в прежних трех cfg; редактировать их вручную для обычного использования не требуется.

## Совместимость и ограничения
Поддерживается только `Assembly-CSharp.dll` размером 3 223 040 байт, SHA-256 `7acb920771bb47779d29c9a4534c78a601837c6af8bce096ea46cb63d212aa23`. Неизвестный IL отклоняется. Конфликты возможны с модами, меняющими те же авиационные, UI и навигационные методы; сторонние Harmony-патчи намеренно не снимаются. Сохранения не преобразуются. Уже существовали отдельные NRE в `UISquadronListElement.SetTarget` и `FlightAIAgent`; этот набор не обещает исправления всех ошибок игры, роста FPS или полной стабильности.

## Разработка и отчеты
`./build.ps1 -GamePath 'D:\Games\Victory At Sea Pacific'` подключает локальные библиотеки, не распространяет их. `tests/packaging.ps1` принимает тот же параметр. CI без игровых DLL может проверять только публичные статические контракты, не собирать игровой код. Лог: `BepInEx/LogOutput.log`; перед отправкой удалите персональные пути/данные сохранений. ## English
Experimental, unofficial community plugins for VASP 1.14.2 (Unity 5.6.7f1 Mono x64). Install BepInEx 5.4.23.5 x64 separately, close the game, then follow INSTALL.md. Independent controls live inside the existing Modifications screen; stock data mods are untouched. Hotfix changes are queued for a full restart; live lifecycle APIs for patrol, convoy and RU require runtime validation. Not a full translation, stability guarantee or FPS claim. No game libraries, saves, loader binaries or private test probes are distributed.
